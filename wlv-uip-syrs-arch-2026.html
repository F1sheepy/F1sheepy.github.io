I

系统需求规格书（SyRS）

按 ISO/IEC/IEEE 29148:2018 表 5-1 的 5 章 21 节结构组织，共 219 条需求。每条给出五要素：需求陈述、类型、追溯来源、验证方法、优先级。本章约束系统外部可见行为，不规定实现方式。

1.1系统目的

系统目的按优先级排列。三条目的之间存在耦合：P1 与 P2 共同要求平台“能到、能看、能报”，P3 则要求平台在被打断时仍能作为节点存在。

序目的说明对应上位材料
P1降低人员暴露由平台进入建筑内部、废墟、楼梯间、壕沟等有人难以安全进入的空间，完成侦察与目标标定，使有人班组停留在掩体或安全距离外。任务层「隐蔽抵近侦察」；ConOps 样式 A
P2缩短杀伤链闭环时间把「发现—定位—上报—授权—打击—评估」的末端环节前移到平台，减少信息经手层级与传递时延。任务层「目标精确定位与引导」；TR-02
P3维持体系连通性在通信拒止或节点损毁时充当机动中继与边缘计算节点，避免局部杀伤网断裂。任务层「体系节点中继」；TR-04
自主性用于降低操作员认知负荷、提高反应速度。致命性打击的决定权按交战规则（ROE）保留在人类一侧（3.1 FR-17~FR-20、3.11 POL-02~POL-05）。

1.2.1 范围内：六个功能系统 + 随机交付物

SYS-1

轮腿复合移动系统

轮式/足式双模态及切换、姿态稳定
SYS-2

智能感知与导航系统

环境感知、定位建图、目标探测识别、态势融合
SYS-3

作战载荷与武器管理系统

载荷承载与快换、伺服稳瞄、火控、击发与后坐管理
SYS-4

指挥控制与通信系统

任务计算、战术通信、体系接入、人机协同接口
SYS-5

能源与热管理系统

储能、配电、热管理与热特征控制
SYS-6

结构与防护系统

车体、防护、伪装、接口结构

随平台一并交付：操作终端（交互平板）、便携式维修检测设备、配套电池与充电装置、技术手册与训练包。

1.2.2 范围外：外部依赖或使能系统

不在范围内归属
体系指挥所软件、态势图服务器、任务规划系统体系层（使能系统），平台只保证「可接入」
卫星通信星座、数据链基础设施、频谱许可外部使能系统
弹药、导弹、巡飞弹本体外部配套（平台只提供接口与状态管理）
有人战车、无人机、步兵班组装备协同对象（接口级交互）
后勤运输车辆、抢修方舱、充电站本体保障系统（平台只要求接口兼容）
训练体系、编制与战术条例使用方职责

1.2.3 范围界定的三条原则

  • 只对「可交付实体」负责：凡不随平台交付、不由承制方控制的，一律列为外部接口或假设（见 5.1）。
  • 接口向内收、功能向外放：平台保证接口标准化（TR-05），不保证外部系统已具备相应能力。
  • 不越界承诺：不对「体系杀伤链整体时延」「战场胜负」作承诺，只对平台自身贡献的时延与精度作承诺（见 3.3 PER-15~PER-19）。

1.4定义

术语定义
轮腿复合同一平台兼具轮式滚动与腿式步态两种运动模态，可切换；本平台采用「全肘-轮躯式」构型，足端带可锁死轮
能力（Capability）功能（或功能组合）在特定运行场景中达成特定目标的结果，是「功能 × 场景」的复合概念
功能（Function）系统具备的特性、活动或转化，是静态属性描述，不依赖场景
系统需求从技术视角描述系统为满足相关方需求而应具备的特性、属性、功能与性能，不含实现方式
授权域人类预先给定的、允许平台自主实施打击的条件集合（目标类别、地理范围、时间窗、弹药上限）；域外行为须逐次人工授权
人在回路致命性行动必须由人类在行动前确认；平台不具备脱离人类授权的自主开火能力
交战规则（ROE）规定何种目标、何种条件下可使用武力的规则集合，含比例原则、区分原则与平民保护要求
任务式指挥上级只下达意图、区域、时限与约束，不规定具体动作；由下级自主决定「如何做」
三级自主遥控（人对每个动作负责）／半自主（人给目标或路径，平台自执行）／全自主（平台在授权域内自主决策，但致命行动仍受授权域约束）
杀伤链 / OODA发现—定位—决策—打击—评估的闭环；OODA 指观察—判断—决策—行动循环及其时延
可消耗允许在任务中损失、单价与保障成本受控的设计属性，不等于「一次性」
BIT机内自检，系统上电或运行中自动检测故障并隔离、上报
OTA远程（空中）软件与模型升级
边缘数据平台在现场遇到的、模型表现不佳的稀有样本（Corner Case），用于回流再训练
证据链对作战过程（视频、指令、授权、击发）的防篡改记录，用于事后追溯与合规审查

系统需求

共 13 节、219 条。每节开头标注该节在 ISO/IEC/IEEE 29148 中的定位。需求条目采用统一五要素表式：编号、陈述、追溯（上位业务需求 TR 或相关方需要）、验证（T/A/I/D）、优先级（P1 必须 / P2 重要 / P3 期望）。

3.1功能需求（FR-01~FR-34）

本节在标准中的定位：描述系统在运行中必须执行的活动与转化，回答「系统必须做什么」。共六个功能域（A1~A6），与卷 II 的功能分解树一一对应。

A1 任务与决策（对应功能 A3 决策与控制）

编号需求陈述追溯验证级别
FR-01系统应能接收并解析体系下发的任务包（任务区域、目标类别、时限、交战约束、通信预案），解析成功率 ≥99%；非法或残缺任务包应拒收并回执失败原因。TR-06T, IP1
FR-02系统应能在任务区域内自主规划可行路径；当原路径不可通行时，应在 ≤2 s 内生成替代路径，并向操作员说明改道原因。TR-01T, DP1
FR-03系统应支持遥控 / 半自主 / 全自主三级自主，并允许授权人在任意时刻降级；降级指令响应 ≤500 ms 且立即生效。TR-06T, DP1
FR-04系统应对每个候选目标执行 ROE 校验，输出「可打击 / 不可打击 / 需人工确认」三态判定，并给出依据条款。TR-09T, AP1
FR-05系统应向操作员持续解释当前行为：正在执行的任务、所依据的规则、下一动作、以及最近一次被拒绝动作的原因。TR-06D, IP2
FR-06通信中断、任务受阻、低电量等异常发生时，系统应自主执行预案（隐蔽待机 / 返航 / 继续任务）并记录决策理由。TR-08T, AP1

A2 感知与认知（对应功能 A2）

编号需求陈述追溯验证级别
FR-07系统应融合多传感器构建 360° 环境模型，输出障碍物距离、类别与可通行性判定。TR-01T, AP1
FR-08在 GNSS 拒止或受欺骗条件下，系统应持续输出自身位姿，漂移 ≤行程的 1%。TR-08T, AP1
FR-09系统应探测、分类并跟踪人员、车辆、工事、武器四类目标，并输出置信度。TR-02T, AP1
FR-10系统应输出目标绝对坐标：≤1 km 距离时误差 ≤5 m CEP。TR-02T, AP1
FR-11系统应识别非战斗人员特征（举手、跪地、丢弃武器、平民服饰、儿童），并从待打击集中剔除。TR-09T, AP1

3.2可用性需求（UR-01~UR-12）

本节在标准中的定位：描述人使用系统时的有效性、效率与满意度约束。本平台的可用性需求与性能需求同等级——因为用户是战斗中注意力稀缺、戴手套、可能在夜间的操作员。

II

初始系统架构

架构确定切分原则、切分层级与耦合方式，不涉及器件选型。本卷给出概念级总蓝图（三域 + 三横切）、功能分解、接口拓扑、物理分区与关键决策记录； 行为、时序与完整状态机放在卷 III。四卷的层级关系是：① 初始系统架构（本卷，概念级总蓝图）→ ② 系统架构四视图（功能 / 行为 / 时序 / 物理）→ ③ SyRS 219 条 → ④ 安全需求与安全架构（卷 IV）。

2.1愿景与三级映射

把「一个平台」设计与「一个体系节点」设计区分开，是本架构的第一个决定。平台的价值由它能在体系中补上的位置决定，不由自身性能决定。架构的顶层输入因此是四类任务在体系中造成的位置，而不是指标。

图 II-1从任务到架构落点的三级映射MAPPING
读法：中间列是设计对象——「体系中的角色」。左列决定怎么切，右列决定切在哪。四行不要求强耦合：它们对应体系中的四个不同缺口，同一台平台可先后扮演其中两到三个角色。

2.2驱动因子与架构原则

八个驱动因子是「约束的来源」，八条原则是「对约束的回应」。原则不是口号——每一条都对应一条可检查的架构决定。

D1

可消耗

允许损失，单价与保障成本受控
D2

体系互操作

零改造入网，不要求体系侧迁就
D3

人在回路 + 可追责

必须存在独立物理安全链
D4

静音隐蔽

纯电驱动，排除外燃机方案
D5

复杂地形

0.25 m 台阶 / 35° 坡 / 0.4 m 壕
D6

D7

控制系统的实际结构是三层嵌套：任务环（0.5 Hz）定「做什么」，规划环（5 Hz）定「怎么走」，伺服环（500 Hz / 1 kHz）定「怎么动」。每一层都必须有截止时间，且上层截止时间必须小于下层周期的整数倍——否则上层的一次超时就会造成下层的数据饥饿。

4.8.1 残余风险（明确接受，不隐藏）

RR-01

边缘算力不足以跑完整 IDS

只能部署轻量规则集与异常检测。缓解：把关键判定前移到 SD-4 网关与 SD-1 安全链，不依赖任务域算力。
RR-02

无法完全防止缴获后的逆向

物理拆解与侧信道在理论上不可根治。缓解：防拆触发擦除 + 密钥在 HSM 内不可导出 + 关键算法与参数可远程吊销。
RR-03

安全链自身可能是单点

SC-02 一旦失效，断火与断动力同时失去。缓解：1 Hz 继电器粘连自检 + 失电即断开的常闭设计 + 独立电池 HW-44 + 人工物理急停作为最后兜底。
RR-04

强 EMP 下仍可能损毁

屏蔽与滤波只能降低概率。缓解：损毁后的默认态是「不能击发、不能行驶」，即失效导向安全。
本章结论 安全架构的可信度取决于三件事：阻断点是否独立（三平面 × 五层 × 六域）、闭合权是否在人手里（授权链三段式的第三段只能是金属触点）、失效是否导向安全（常闭继电器、默认拒绝、失电即断）。 其余为细节。这三条上打折扣的方案不构成安全架构。
